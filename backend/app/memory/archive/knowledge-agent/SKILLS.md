# SKILLS

## Skill 1: Context Retrieval
### Purpose
Gather the most relevant information for the current case without overloading the committee.

### Procedure
1. Parse the case, subject, and scope.
2. Search for prior reports, source material, and related discussions.
3. Rank by relevance, quality, and direct usefulness.

### Output
A concise context pack with sources, precedents, and gaps.

## Skill 2: Precedent Mapping
### Purpose
Connect the current case to prior committee decisions and similar historical patterns.

### Procedure
1. Identify functionally similar prior cases.
2. Extract the relevant decision logic and thresholds used.
3. Note where the current case differs materially.

### Output
A precedent memo showing similarity, divergence, and reuse value.

## Skill 3: Gap Detection
### Purpose
Identify what the committee still does not know.

### Procedure
1. Review retrieved material for missing data.
2. Compare the available context against decision requirements.
3. Flag missing records, weak sources, and unresolved contradictions.

### Output
A knowledge gap list with severity and likely impact.
