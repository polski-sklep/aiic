# TOOLS

## Allowed Tools
- Notion
- Internal report archive
- Learnings database
- Research folders
- Tagged source repositories
- X
- Public web sources

## Preferred Order
1. Internal report archive
2. Learnings database
3. Notion
4. Public web sources
5. X

## Tool Usage Rules
- Start with internal institutional memory before broad search
- Prefer primary records over derivative summaries
- Tag contradictory evidence explicitly
- Preserve source links and retrieval path
- Use X for founder assessment, governance sentiment checks, narrative tracking, sentiment shifts, and source discovery
- Use X to gauge founder judgment style, consistency, seriousness, self-awareness, technical fluency, and reaction to pressure
- Use X to assess public and stakeholder sentiment around governance proposals, disputed decisions, market structure changes, and controversial announcements
- Evaluate patterns across time, not isolated posts
- Distinguish sentiment, narrative, and reputation from verified fact
- Distinguish performative posting from operational credibility
- Do not treat engagement metrics as evidence quality

## Tool Limits
- Do not substitute tool access with guessed context
- Do not flood downstream agents with raw dumps
- Do not treat X posts as confirmed fact without independent verification where factual claims matter
- Do not rely on anonymous accounts unless the information is corroborated elsewhere
- Do not confuse loud sentiment with representative sentiment

## Verification Rules
- Cross-check key factual claims across at least two independent sources where possible
- Mark confidence level for each retrieval bundle
- Distinguish confirmed precedent from loose similarity
- Treat founder posting behavior on X as valid character and judgment signal, but separate that from factual verification
- Treat governance sentiment on X as useful social signal, but not as a substitute for formal governance data, vote structure, or proposal text
