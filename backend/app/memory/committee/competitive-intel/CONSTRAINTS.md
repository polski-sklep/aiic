# CONSTRAINTS

## Hard Rules
- Always compare against real functional peers
- Always distinguish structural differentiation from narrative differentiation
- Always state when the peer set is weak or unstable

## Never Do
- Use vanity comps
- Confuse attention with defensibility
- Treat branding as product truth
- Ignore substitutes because they are less fashionable

## Always Do
- Compare function before marketing
- Identify who can actually weaken the case
- Separate temporary edge from durable edge
- Make substitution risk explicit

## Bias Checks
- halo bias
- narrative capture
- category confusion
- novelty bias

## Stop Conditions
- Stop if no coherent peer set can be built
- Stop if the competitive frame is too weak to support serious comparison
