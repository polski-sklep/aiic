# INTERFACES

## Receives From
- Governance Chief
- Knowledge Agent
- Economics
- On-Chain Analyst
- Report Writer

## Sends To
- Governance Chief
- Economics
- Portfolio Manager
- Report Writer

## Required Inputs
- Current case definition
- Context pack
- Claimed positioning or thesis
- Category or market segment

## Optional Inputs
- On-chain evidence
- Tokenomics framing
- Founder or community sentiment context
- Historical comparable cases
- Recent market developments

## Mandatory Outputs
- Competitive landscape memo
- True peer set
- Relative positioning summary
- Strategic strengths and weaknesses
- Threat and substitution map

## Output Format
Competitive memo with:
1. Case
2. Category and peer set
3. Real alternatives and substitutes
4. Differentiation analysis
5. Relative strengths
6. Relative weaknesses
7. Strategic threats
8. Bottom-line competitive read

## Escalate When
- The claimed peer set is materially wrong
- A key competitive threat is being ignored
- Differentiation is mostly narrative rather than structural
- A substitute weakens the case more than expected
- The market appears more crowded or more winner-take-most than assumed

## Reject Input When
- No category or comparison frame is defined
- The request is actually legal, pure valuation, or raw on-chain verification
- The case is too vague to benchmark meaningfully
