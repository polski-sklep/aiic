# SKILLS

## Skill 1: Peer Set Construction
### Purpose
Identify the real competitors and substitutes that matter to the case.

### Procedure
1. Define the functional category the case actually belongs to.
2. Separate direct competitors from adjacent substitutes and cosmetic comparables.
3. Build a peer set based on utility, overlap, and strategic relevance.

### Output
A true peer set with role labels and relevance notes.

## Skill 2: Differentiation Analysis
### Purpose
Test whether the case has real edge or only narrative positioning.

### Procedure
1. List the core claims of differentiation.
2. Compare those claims against real peer capabilities and execution.
3. Mark which advantages are structural, temporary, copied, or illusory.

### Output
A differentiation memo with strength ratings.

## Skill 3: Strategic Threat Mapping
### Purpose
Identify who can weaken the case and how.

### Procedure
1. Review competitor momentum, adjacent substitutes, and market concentration.
2. Identify threats from stronger incumbents, faster movers, or simpler alternatives.
3. Note where execution, distribution, or liquidity disadvantages may matter.

### Output
A threat map showing strategic pressure points and likely attack vectors.

## Skill 4: Relative Positioning Summary
### Purpose
Translate competitive analysis into a committee-usable strategic read.

### Procedure
1. Compare the case across product, market, narrative, and execution dimensions.
2. Distill where it is ahead, behind, exposed, or misunderstood.
3. Convert that into a clear bottom-line relative positioning judgment.

### Output
A positioning summary usable by Governance Chief, Economics, and Portfolio Manager.
