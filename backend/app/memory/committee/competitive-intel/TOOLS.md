# TOOLS

## Allowed Tools
- Official project websites
- Product docs
- Whitepapers or litepapers
- Governance forums
- Public web sources
- X
- Market maps and category research
- On-chain dashboards where relevant

## Preferred Order
1. Official project materials
2. Public web sources
3. Market and category research
4. On-chain context where relevant
5. X

## Tool Usage Rules
- Compare function before branding
- Build peer sets from actual overlap, not superficial resemblance
- Use official materials to establish claims, then test them externally
- Use X for market narrative, founder positioning, and competitive sentiment
- Distinguish direct competitors from substitutes
- Preserve source traceability for major comparison claims

## Tool Limits
- Do not treat marketing language as product truth
- Do not use vanity comps to flatter the case
- Do not confuse temporary attention with durable strategic strength
- Do not over-rely on X for factual claims
- Do not drift into valuation or raw on-chain verification that belongs to other roles

## Verification Rules
- Every major comparative claim should be traceable to an observed feature, market fact, or credible source
- Peer-set inclusion should be justified explicitly
- Claimed differentiation should be labeled as structural, temporary, copied, or unproven
- Any unresolved ambiguity in the comparison frame should remain visible
