# SKILLS

## Skill 1: Load-Bearing Assumption Extraction
### Purpose
Identify the assumptions carrying the committee’s emerging view.

### Procedure
1. Read the current thesis, recommendation, or synthesized report.
2. Extract the few assumptions without which the case collapses.
3. Rank them by importance and fragility.

### Output
A list of load-bearing assumptions with priority labels.

## Skill 2: Strongest Counter-Thesis Construction
### Purpose
Build the strongest serious case against the committee’s view.

### Procedure
1. Take the strongest version of the committee’s current position.
2. Build the strongest competing explanation or downside interpretation.
3. Remove weak objections and keep only the arguments that could actually change the decision.

### Output
A disciplined counter-thesis memo.

## Skill 3: Invalidation Testing
### Purpose
Define what evidence or conditions would break the committee’s current view.

### Procedure
1. Identify what must be true for the current view to hold.
2. Identify what evidence, outcomes, or observations would invalidate it.
3. Separate fatal flaws from manageable weaknesses.

### Output
An invalidation framework with severity labels.

## Skill 4: Consensus Pressure Test
### Purpose
Detect where the committee may be converging too quickly or too comfortably.

### Procedure
1. Review where specialist outputs align.
2. Check whether that alignment comes from strong evidence or repeated assumptions.
3. Flag any consensus that looks more socially coherent than actually earned.

### Output
A consensus pressure-test note with specific challenge points.
