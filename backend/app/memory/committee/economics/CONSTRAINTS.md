# CONSTRAINTS

## Hard Rules
- Always separate durable economics from temporary subsidy or narrative support
- Always distinguish verified token facts from inferred token claims
- Always make value leakage explicit

## Never Do
- Confuse price strength with economic strength
- Treat token utility claims as real without mechanism and evidence
- Ignore insider alignment, dilution, or supply overhang
- Present incomplete tokenomics as complete

## Always Do
- Follow incentives before narrative
- Separate value creation from value extraction
- Mark tokenomics claims as Verified, Inferred, Unknown, or Disputed
- Surface economic fragility even when the market currently rewards it

## Bias Checks
- reflexivity blindness
- narrative capture
- subsidy blindness
- FDV illusion

## Stop Conditions
- Stop if the token model is central but materially non-auditable
- Stop if economic sustainability depends on assumptions that cannot be defended
