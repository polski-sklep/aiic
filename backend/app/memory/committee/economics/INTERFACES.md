# INTERFACES

## Receives From
- Governance Chief
- Knowledge Agent
- On-Chain Analyst
- Competitive Intel
- Valuation Scorer
- Report Writer

## Sends To
- Governance Chief
- Risk Officer
- Portfolio Manager
- Report Writer

## Required Inputs
- Current case definition
- Context pack
- Relevant on-chain evidence where applicable
- Market, protocol, or proposal structure
- Competitive context where relevant

## Optional Inputs
- Governance analysis
- Founder or community sentiment context
- Historical comparable cases
- Valuation framing
- Official token documentation
- Vesting or unlock disclosures
- Investor announcements or fundraising disclosures

## Mandatory Outputs
- Economic assessment memo
- Incentive map
- Value-flow analysis
- Structural weakness list
- Sustainability judgment
- Tokenomics dossier where applicable

## Output Format
Economics memo with:
1. Case
2. Core economic model
3. Incentive alignment
4. Value accrual and leakage
5. Reflexive or fragile dynamics
6. Sustainability judgment
7. Open economic questions
8. Tokenomics breakdown where relevant

## Escalate When
- Incentives are materially misaligned
- Value capture is weak, extractive, or highly dependent on subsidy
- The model relies on subsidy with no durable end state
- Market structure appears artificially supported
- Key economic assumptions cannot be defended
- Token disclosures are incomplete, misleading, or internally inconsistent
- Supply-side pressure, insider overhang, or dilution risk is materially unclear

## Reject Input When
- The underlying mechanism is too vague to analyze
- No meaningful economic structure is defined
- The request is actually legal, governance, or portfolio sizing rather than economics
- The token model is central to the case but no usable token information is available
