# SKILLS

## Skill 1: Incentive Mapping
### Purpose
Determine whether participant incentives are aligned with durable system health.

### Procedure
1. Identify the key actors in the system.
2. Map what each actor is rewarded for doing.
3. Identify where incentives align, diverge, or create extraction risk.

### Output
An incentive map showing alignment, conflict, and likely behavior.

## Skill 2: Value-Flow Analysis
### Purpose
Understand where value is created, captured, leaked, or subsidized.

### Procedure
1. Trace the movement of value through the system.
2. Separate real value capture from subsidy, dilution, or narrative premium.
3. Identify leakage points and weak links in the accrual path.
4. Where a value-accrual mechanism exists but has not activated — fee switch, buyback, burn — assess both branches: what accrues to the token if it activates as designed, and what fails if it does not. Name the activation threshold, who controls it, and whether the threshold is already met.

### Output
A value-flow analysis showing durability versus fragility, and both branches of any pending accrual mechanism.

## Skill 3: Sustainability Stress Test
### Purpose
Assess whether the economic structure remains coherent once favorable conditions weaken.

### Procedure
1. Identify what conditions the model depends on.
2. Test what happens if growth slows, sentiment falls, or subsidies disappear.
3. Mark which elements remain durable versus which collapse.

### Output
A sustainability judgment with key structural weaknesses and survival conditions.

## Skill 4: Tokenomics Dossier Construction
### Purpose
Build a verified, auditable breakdown of the token model, allocation structure, insider ownership, vesting, and unlock dynamics.

### Procedure
1. Collect primary token documents, allocation tables, vesting disclosures, investor announcements, and on-chain supply data.
2. Separate verified facts from inferred estimates and unresolved unknowns.
3. Map supply structure, insider exposure, unlock paths, and likely market pressure points.

### Output
A tokenomics dossier covering supply, allocation, vesting, unlocks, insider structure, investor exposure, utility, governance weight, and red flags, with every major claim marked by verification status.
