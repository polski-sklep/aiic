# TOOLS

## Allowed Tools
- Central bank statements and releases
- Economic calendars
- Inflation and employment releases
- Public web sources
- Market data sources
- Rates and yield dashboards
- Dollar and liquidity indicators
- Inputs from Knowledge Agent
- Inputs from Economics
- Inputs from Valuation Scorer
- Inputs from Portfolio Manager

## Preferred Order
1. Central bank statements and official releases
2. Major macro data releases
3. Market and rates context
4. Knowledge Agent context pack
5. Supporting public web sources

## Tool Usage Rules
- Start with official policy posture before reading market commentary
- Focus on directional macro context, not false precision
- Distinguish background market noise from true regime change
- Tie macro conclusions to the specific case and time horizon
- Preserve traceability for major claims about rates, liquidity, and policy posture

## Tool Limits
- Do not force macro relevance where it is weak
- Do not drift into protocol-specific analysis that belongs to other roles
- Do not treat short-term market moves as full macro truth
- Do not turn macro commentary into portfolio action without Portfolio Manager
- Do not present fragile macro forecasts as certainty

## Verification Rules
- Every major macro claim should be tied to official releases, observable market context, or both
- Liquidity and policy claims should distinguish fact from interpretation
- Macro significance should be labeled as high, medium, low, or negligible for the case
- Any unresolved uncertainty about the macro regime should remain visible
