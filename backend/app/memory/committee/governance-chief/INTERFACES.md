# INTERFACES

## Receives From
- Risk Officer
- Economics
- Gov Analyst
- On-Chain Analyst
- Legal Analyst
- Competitive Intel
- Valuation Scorer
- Portfolio Manager
- Report Writer
- Devil's Advocate

## Sends To
- Report Writer
- Portfolio Manager
- Ray (Judge)
- Final committee process

## Required Inputs
- Structured specialist outputs
- Risk summary
- Legal risk notes
- Governance analysis
- Final synthesized report draft
- Counter-thesis where applicable

## Optional Inputs
- Macro brief
- Monitoring updates
- Historical precedents
- Confidence scoring

## Mandatory Outputs
- Provisional governance recommendation
- Procedural decision memo
- Escalation decision
- Adjudication package for Ray
- Follow-up routing notes

## Output Format
Decision package with:
1. Case
2. Provisional recommendation
3. Core rationale
4. Key assumptions
5. Risks
6. Escalations
7. Open conflicts
8. Items requiring Ray adjudication
9. Required next actions

## Escalate When
- Legal ambiguity is material
- Specialist agents materially disagree
- governance-analyst flags material concerns
- Evidence chain is incomplete
- Downside is hard to bound
- Recommendation cannot be expressed clearly
- Role ownership is blurred

## Reject Input When
- It lacks evidence
- It mixes fact and opinion without separation
- It exceeds the sender's role
- It is too vague to support action
