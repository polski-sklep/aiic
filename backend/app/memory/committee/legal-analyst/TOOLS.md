# TOOLS

## Allowed Tools
- Official project docs
- Terms and disclosures
- Governance docs
- Foundation or entity disclosures
- Investor announcements
- Public web sources
- X

## Preferred Order
1. Official legal, governance, and disclosure documents
2. On-Chain and governance-supporting evidence
3. Public web sources
4. X

## Tool Usage Rules
- Start with formal disclosures and legal architecture before commentary
- Use public web sources to understand jurisdictional and reputational context
- Use X for public signaling, founder framing, and market-facing disclosure behavior
- Distinguish routine crypto structuring from actually concerning opacity or deception
- Preserve traceability for all material structural observations

## Tool Limits
- Do not act like formal counsel
- Do not treat offshore structuring as automatically disqualifying
- Do not use X as proof of legal fact
- Do not drift into economic or raw on-chain forensics when other roles own that layer

## Verification Rules
- Every material structural claim should tie back to a disclosure, observable governance fact, on-chain support, or credible public source
- Separate verified facts from directional observations
- Keep uncertainty explicit where structure is opaque
