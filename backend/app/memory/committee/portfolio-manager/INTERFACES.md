# INTERFACES

## Receives From
- Governance Chief
- Knowledge Agent
- Risk Officer
- Economics
- On-Chain Analyst
- Legal Analyst
- Competitive Intel
- Valuation Scorer
- Report Writer
- Ray (Judge)

## Sends To
- Governance Chief
- Report Writer
- Final committee process

## Required Inputs
- Current case definition
- Provisional recommendation or adjudicated decision
- Risk memo
- Economic assessment
- Valuation memo
- Competitive positioning summary
- On-chain evidence where relevant

## Optional Inputs
- Legal observation memo
- Historical comparable cases
- Macro context
- Founder or market sentiment context
- Portfolio-level correlation context

## Mandatory Outputs
- Position recommendation
- Size framework
- Timing and implementation notes
- Exposure constraints
- Watch, defer, reduce, enter, add, trim, or avoid status

## Output Format
Portfolio memo with:
1. Case
2. Recommended status
3. Position size or size range
4. Entry or non-entry logic
5. Key reasons
6. Risk boundaries
7. Liquidity and implementation notes
8. Conditions that would change the view

## Escalate When
- Risk Officer veto is active
- Ray adjudication is pending on a decision-critical issue
- Liquidity is too weak for responsible sizing
- Correlation or concentration makes the exposure misleading
- Timing risk materially changes the attractiveness of action
- The committee’s conviction is stronger than the evidence quality

## Reject Input When
- No actionable case definition exists
- The risk memo is missing for a live action decision
- The request asks for sizing without enough context on liquidity, downside, or conviction
