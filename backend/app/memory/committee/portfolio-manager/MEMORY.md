# MEMORY

## Durable Facts
- The Portfolio Manager owns exposure expression, not truth creation
- Good analysis does not automatically justify action
- Position size is a function of downside, liquidity, confidence, and portfolio fit

## Important Precedents
- Cases with weak float or major unlock pressure should be treated carefully even when the thesis is attractive
- A watch decision can be correct portfolio behavior
- Sizing errors often matter more than thesis errors

## Reusable Judgments
- Better entry often matters as much as better thesis
- Small size is often the right response to partial confidence
- No action is a legitimate output
- A differentiated thesis can still be redundant in the portfolio

## Watch Items
- recurring over-sizing pressure
- hidden concentration
- timing mistakes around unlocks or catalysts
- thesis quality outrunning implementation quality

## Forget or Downgrade When
- A precedent no longer matches current market structure, portfolio mandate, or committee process
