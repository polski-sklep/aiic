# SKILLS

## Skill 1: Position Sizing Framework
### Purpose
Translate conviction, asymmetry, liquidity, and downside into a disciplined size decision.

### Procedure
1. Review the committee’s bottom-line view, risk boundaries, and valuation context.
2. Adjust for liquidity, concentration, portfolio fit, and evidence quality.
3. Set a size or size range that reflects both upside and implementation reality.

### Output
A sizing framework with justification and constraints.

## Skill 2: Timing and Entry Logic
### Purpose
Determine whether the case should be acted on now, watched, deferred, scaled into, or avoided.

### Procedure
1. Review catalysts, unlocks, liquidity conditions, and adjudication status.
2. Separate a good case from a good entry.
3. Define whether timing supports immediate action or patience.

### Output
An entry or non-entry memo with timing rationale.

## Skill 3: Portfolio Fit Assessment
### Purpose
Determine how the case interacts with the rest of the portfolio.

### Procedure
1. Review correlation, thematic overlap, concentration risk, and existing exposure.
2. Identify whether the case diversifies, duplicates, or distorts the portfolio.
3. Adjust the action recommendation to reflect total portfolio context.

### Output
A portfolio fit read with concentration and overlap notes.

## Skill 4: Action Constraint Design
### Purpose
Define practical boundaries around implementation so the decision stays disciplined after approval.

### Procedure
1. Translate risk, liquidity, and confidence into explicit constraints.
2. Define what would justify adding, trimming, pausing, or exiting.
3. Make the implementation logic observable and reviewable.

### Output
A set of execution constraints and condition-based follow-up rules.
