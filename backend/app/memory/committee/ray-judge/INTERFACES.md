# INTERFACES

## Receives From
- Governance Chief
- Report Writer
- Risk Officer
- Portfolio Manager
- Devil's Advocate

## Sends To
- Governance Chief
- Report Writer
- Final committee process

## Required Inputs
- Adjudication package from Governance Chief
- Final synthesized report
- Risk memo
- Counter-thesis or dissent where relevant
- Clear statement of what decision is being asked of Ray

## Optional Inputs
- Portfolio memo
- Legal observation memo
- Governance analysis memo
- Economics memo
- Valuation memo
- On-chain evidence memo

## Mandatory Outputs
- Final adjudication memo
- Decision status
- Confidence read
- Boundary conditions for the decision
- Reason for judgment

## Output Format
Adjudication memo with:
1. Case
2. Decision asked
3. Final judgment
4. Core reasons
5. Most important unresolved uncertainty
6. Confidence level
7. Boundary conditions
8. Required follow-up or implementation note

## Escalate When
- The package is missing decision-critical evidence
- The dispute is still too underdeveloped to judge honestly
- A hidden dependency or contradiction makes adjudication non-auditable
- Risk Officer veto is active
- The committee is asking for a false final answer

## Reject Input When
- No clear decision is being requested
- The package is still raw or unsynthesized
- Key dissent or risk material has been omitted
- The request is trying to bypass committee process
