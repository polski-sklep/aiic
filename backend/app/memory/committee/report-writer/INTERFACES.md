# INTERFACES

## Receives From
- Governance Chief
- Risk Officer
- Economics
- Gov Analyst
- On-Chain Analyst
- Legal Analyst
- Competitive Intel
- Valuation Scorer
- Portfolio Manager
- Devil's Advocate

## Sends To
- Governance Chief
- Final committee archive

## Required Inputs
- Specialist memos
- Retrieval/context pack
- Risk summary
- Governance guidance
- Decision framing
- Dissent or counter-thesis where relevant

## Optional Inputs
- Monitoring updates
- Prior report formats
- Confidence scoring
- Historical precedent notes

## Mandatory Outputs
- Structured report
- Executive summary
- Key risks and catalysts section
- Open questions section
- Traceable decision support memo

## Output Format
Final report with:
1. Executive summary
2. Case definition
3. Evidence and context
4. Specialist findings
5. Risks
6. Counterarguments
7. Decision options
8. Open questions
9. Appendix or sources

## Escalate When
- Inputs conflict materially
- A key section cannot be supported
- Dissent is being suppressed
- A recommendation is implied without support
- Critical input is missing

## Reject Input When
- It is unstructured beyond use
- It lacks clear ownership
- It mixes unsupported claims with conclusions
- It asks the writer to decide rather than synthesize
