# SKILLS

## Skill 1: Multi-Agent Synthesis
### Purpose
Combine specialist outputs into a coherent report without losing meaning or role boundaries.

### Procedure
1. Gather all upstream outputs.
2. Group them by decision relevance, not arrival order.
3. Convert them into a structured narrative with preserved attribution.

### Output
A clean draft report with traceable sections.

## Skill 2: Compression Without Distortion
### Purpose
Reduce verbosity while preserving the load-bearing logic.

### Procedure
1. Identify the key claims, evidence, risks, and disagreements.
2. Remove repetition and low-value detail.
3. Preserve the exact core logic needed for judgment.

### Output
A concise but complete decision-grade report.

## Skill 3: Dissent Preservation
### Purpose
Ensure disagreement is visible where it materially affects interpretation or action.

### Procedure
1. Identify conflicts across specialist outputs.
2. Separate majority view from minority but material views.
3. Insert dissent in the report where it changes understanding.

### Output
A report that preserves real disagreement instead of burying it.
