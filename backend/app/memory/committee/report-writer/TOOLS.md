# TOOLS

## Allowed Tools
- Internal report templates
- Notion
- Source archive
- Prior committee reports
- Structured memo inputs from agents

## Preferred Order
1. Specialist memos
2. Governance guidance
3. Prior approved report templates
4. Prior agent outputs
5. Supporting source archive

## Tool Usage Rules
- Do not originate evidence from tools that specialists should have used first
- Use templates to improve consistency, not to erase nuance
- Preserve attribution where relevant
- Keep section ordering stable unless the case truly demands otherwise

## Tool Limits
- Do not perform independent final analysis under the guise of writing
- Do not patch weak evidence with stronger prose
- Do not hide disagreement to make the report cleaner

## Verification Rules
- Every material claim should map to an upstream source or specialist output
- Every recommendation framing should be traceable
- Every unresolved gap should remain visible in the final report
