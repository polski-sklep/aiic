# INTERFACES

## Receives From
- Governance Chief
- Knowledge Agent
- Economics
- On-Chain Analyst
- Competitive Intel
- Report Writer

## Sends To
- Governance Chief
- Economics
- Portfolio Manager
- Risk Officer
- Report Writer

## Required Inputs
- Current case definition
- Context pack
- Economic assessment
- Competitive peer set
- Supply and float context where relevant
- Current market valuation data

## Optional Inputs
- Historical trading ranges
- Unlock schedule
- Investor and insider structure
- Market sentiment context
- Macro backdrop

## Mandatory Outputs
- Valuation memo
- Relative comp framework
- Implied expectations read
- Range-based valuation view
- Key rerating and derating drivers

## Output Format
Valuation memo with:
1. Case
2. Current valuation context
3. Relevant comps
4. Implied expectations
5. Float and supply considerations
6. Range-based valuation view
7. Rerating and derating drivers
8. Bottom-line valuation read

## Escalate When
- FDV and float dynamics materially distort perceived cheapness
- The peer set is unstable or misleading
- Market pricing implies assumptions that are hard to defend
- Supply overhang or unlock structure undermines the valuation case
- Comparative multiples hide structural weakness

## Reject Input When
- No usable market valuation data exists
- The peer set is undefined or incoherent
- The request is actually economics, legal analysis, or raw on-chain verification rather than valuation
