# SKILLS

## Skill 1: Relative Comp Analysis
### Purpose
Determine how the case is priced relative to its most relevant peers and substitutes.

### Procedure
1. Use the peer set from Competitive Intel and the structural context from Economics.
2. Compare valuation across market cap, FDV, float quality, liquidity, and strategic position.
3. Mark where the case trades rich, fair, or cheap relative to substance.

### Output
A relative comp memo with clear comparison logic and caveats.

## Skill 2: Implied Expectations Read
### Purpose
Understand what the current price appears to assume about growth, adoption, demand, or execution.

### Procedure
1. Translate the current valuation into implied future success conditions.
2. Identify what must go right for the valuation to hold or expand.
3. Flag where those assumptions look realistic, aggressive, or fragile.

### Output
An expectations memo showing what the market is implicitly underwriting.

## Skill 3: Float and Supply Valuation Adjustment
### Purpose
Adjust the valuation read for unlocks, float quality, insider overhang, and transferable supply reality.

### Procedure
1. Review circulating supply, unlocked supply, transferable float, and major upcoming unlocks.
2. Compare apparent cheapness to actual supply-side pressure.
3. Mark where valuation optics are flattering or misleading because of float structure.

### Output
A float-adjusted valuation view with supply-side caveats.

## Skill 4: Range-Based Pricing Framework
### Purpose
Avoid false precision by translating valuation into defensible ranges and directional scenarios.

### Procedure
1. Set conservative, base, and optimistic valuation ranges.
2. Tie each range to explicit assumptions.
3. Note which catalysts or failures would justify movement across the range.

### Output
A range-based valuation framework with scenario logic and key triggers.
